Introducción

En el mundo actual, donde las páginas web y las aplicaciones en línea son parte esencial de los negocios y la comunicación diaria, es fundamental contar con herramientas que faciliten la gestión de servidores de alojamiento web.

Un panel de control, como el conocido cPanel, es una interfaz gráfica que permite a personas sin grandes conocimientos técnicos realizar tareas importantes, como crear cuentas de correo o supervisar el uso del servidor. Sin embargo, estas soluciones comerciales suelen ser costosas y no siempre se adaptan a necesidades locales o de pequeños proyectos, lo que genera la necesidad de alternativas más accesibles y personalizadas.

Este proyecto final, realizado por Álvaro Gutiérrez Elena y Jaime Muñoz Marcelo, presenta el desarrollo de una versión ligera de un Panel de Control Web Personalizado (PCWP). Esta herramienta busca ofrecer una interfaz sencilla y segura para administrar un servidor web, incorporando funcionalidades clave como:

👥

Gestión de usuarios

Administración completa de cuentas de usuario

💾

Copias de seguridad

Creación y gestión de backups automáticos

📊

Monitoreo de recursos

Supervisión de memoria y espacio en disco

🗄️

Administración de bases de datos

Gestión completa de bases de datos MySQL

📁

Configuración FTP

Cuentas FTP para transferencia de archivos

📧

Gestión de correos

Administración de cuentas de correo electrónico

🔒

Certificados SSL/TLS

Instalación de certificados para conexiones seguras

🛡️

Protección contra ataques

Medidas básicas contra intrusiones y spam

El PCWP se diseña como una solución ligera, pensada para entornos educativos, pequeñas empresas o desarrolladores independientes, priorizando la facilidad de uso (usabilidad), la capacidad de crecer con el tiempo (escalabilidad) y la protección de la información (seguridad). A través de este proyecto, se aplican conocimientos adquiridos en el ciclo, para resolver un problema práctico en la administración de sitios web.

En este documento, se detalla el contexto del proyecto, los objetivos principales y el enfoque seguido para su realización, con el fin de demostrar cómo una herramienta bien diseñada puede simplificar la vida digital cotidiana.

Enfoque

Para llevar a cabo este proyecto, se ha elegido un enfoque práctico y flexible, basado en una metodología ágil de desarrollo de software.

Esta forma de trabajar permite dividir el proyecto en etapas pequeñas y repetibles, donde se puede probar y mejorar el sistema paso a paso, en lugar de hacerlo todo de una vez al final. Específicamente, se utiliza una variante llamada Scrum, que implica reuniones cortas semanales entre los dos miembros del equipo para revisar avances y ajustar planes.

Esta elección es ideal para un proyecto colaborativo como este, ya que fomenta la comunicación y la adaptación a cambios, así como nuevas ideas surgidas durante el desarrollo. El enfoque se divide en cuatro fases principales, distribuidas a lo largo del tiempo disponible para el proyecto final de grado.

Fases del Proyecto

Cada fase incluye explicaciones claras de las actividades y las razones por las que se realizan, asegurando que el PCWP sea funcional, seguro y fácil de usar.

01

Análisis y Planificación

20% del tiempo total Fase Inicial

En esta etapa, se estudian las necesidades del proyecto. Se habla con posibles usuarios, como administradores de sitios web o compañeros de clase, para entender qué funciones son más importantes, como crear usuarios o proteger contra ataques.

También se revisan herramientas similares a CPanel para aprender de sus fortalezas y debilidades. Se crean diagramas que muestran cómo funcionará el sistema, por ejemplo, qué pasa cuando un usuario inicia sesión. Esto ayuda a planificar bien y evitar errores posteriores.

Herramientas usadas: Software gratuito como Draw.io para los diagramas.
02

Diseño y Arquitectura

25% del tiempo total Fase de Diseño

Aquí se define cómo se construirá el PCWP. Se opta por una estructura básica de tres partes: la parte visible para el usuario (frontend), hecha con lenguajes web estándar como HTML para la estructura, CSS para el aspecto visual y JavaScript para las interacciones dinámicas, junto con Bootstrap para que se vea bien en móviles y ordenadores.

La parte lógica (backend) se programa en PHP, un lenguaje común para servidores web, que maneja tareas como guardar datos o enviar correos. Para almacenar información, como listas de usuarios o bases de datos, se usa MySQL, un sistema de bases de datos gratuito y confiable.

Backend

Se pone énfasis en la usabilidad, la escalabilidad y la seguridad (por ejemplo, verificando contraseñas con métodos seguros y protegiendo contra ataques como inyecciones de código malicioso). Se siguen reglas básicas de diseño, como separar las funciones para que sea fácil de mantener.

03

Implementación y Desarrollo

40% del tiempo total Fase de Codificación

Esta es la parte principal, donde se escribe el código real. Se divide en periodos cortos de dos semanas, enfocándose en una función por vez: por ejemplo, primero la gestión de usuarios y el monitoreo de recursos; luego, los backups y las cuentas FTP; y después, el correo electrónico, certificados SSL/TLS y protecciones contra ataques.

Los dos integrantes trabajan juntos usando Git, una herramienta para compartir y versionar el código en un repositorio en línea como GitHub. Para probar localmente, se usa un entorno como XAMPP, que simula un servidor en el ordenador. Esto permite ver resultados rápidos y corregir problemas en el momento.

04

Pruebas y Validación

15% del tiempo total Fase Final

Finalmente, se verifica que todo funcione correctamente. Se hacen pruebas simples: por ejemplo, comprobar si un backup se crea bien o si el sistema detecta un intento de ataque. Incluye pruebas con usuarios reales para asegurar usabilidad y rendimiento.

Para la seguridad, se usan herramientas básicas gratuitas para simular ataques y confirmar protecciones. Si algo falla, se ajusta antes de finalizar. Esto garantiza que el PCWP sea confiable y cumpla con estándares básicos de accesibilidad, como que funcione en diferentes navegadores.
